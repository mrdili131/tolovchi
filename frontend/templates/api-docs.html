Bindin API hujjatlari

Bindin API orqali servisingizni bizning obuna va avtomatik to'lov tizimimizga ulashingiz mumkin: arizalar yaratish, mijozlarni QR orqali ulash, kartalardan mablag' yechish va tranzaksiyalar tarixini kuzatish.

Barcha so'rovlar uchun asosiy manzil: https://bindin.uz/api

Autentifikatsiya

Ikki usuldan birini tanlashingiz mumkin:

1. Bearer token (login orqali)
Authorization: Bearer <access_token>
2. API kalit (server-serverga integratsiya)
X-API-Key: bnd_live_...

Hisob

POST /auth/login Ochiq

Login qilib access token oling. application/x-www-form-urlencoded formatida yuboriladi.

So'rov
curl -X POST https://bindin.uz/api/auth/login \
  -d "username=your_service&password=your_password"
Javob 200
{
  "access_token": "eyJhbGciOi...",
  "token_type": "bearer",
  "role": "service"
}
GET /auth/me_service Bearer yoki API kalit

O'z profilingiz va joriy balansingizni olish.

So'rov
curl https://bindin.uz/api/auth/me_service \
  -H "X-API-Key: bnd_live_..."
Javob 200
{
  "id": 2,
  "username": "netflix_uz",
  "service_name": "Netflix Uzbekistan",
  "balance": 4500000,
  "role": "service"
}

Arizalar (obunalar)

GET /application/?page=1&page_size=20 Bearer yoki API kalit

O'zingizga tegishli arizalar ro'yxati, paginatsiya bilan.

So'rov
curl "https://bindin.uz/api/application/?page=1&page_size=20" \
  -H "X-API-Key: bnd_live_..."
Javob 200
{
  "items": [{
    "id": 12, "name": "Netflix obunasi",
    "amount": 45000, "is_active": true,
    "pay_day": 5, "frequency": "monthly",
    "payer": { "id": 7, "username": "vali_a" }
  }],
  "total": 1, "page": 1, "page_size": 20,
  "total_pages": 1, "has_next": false, "has_previous": false
}
POST /application/ Bearer yoki API kalit

Yangi obuna arizasi yaratish. Mijoz uni QR kod orqali skanerlab ulanadi.

So'rov tanasi
{
  "name": "Netflix obunasi",
  "description": "Oylik reja",
  "amount": 45000,
  "frequency": "monthly",
  "pay_day": 5
}
Javob 201
{
  "id": 12, "name": "Netflix obunasi",
  "amount": 45000, "is_active": false,
  "payer": null
}
GET /application/detail/{id} Bearer yoki API kalit

Bitta arizani olish — is_active va is_paid orqali holatini tekshiring.

POST /application/stop/{id} Bearer yoki API kalit

O'zingizga tegishli arizani to'xtatish (faqat servis o'z arizasini to'xtata oladi).

Javob 200
{ "status": true, "detail": "Success" }
Xatolik 404
{ "detail": "Could not find application" }

To'lovlar

POST /card/charge Bearer yoki API kalit

Mijozning bog'langan kartasidan ariza summasini yechish. amount ariza summasidan (application.amount) oshmasligi va ariza shu davr uchun to'lanmagan bo'lishi kerak.

So'rov tanasi
{
  "application_id": 12,
  "amount": 45000
}
Javob 200
{
  "id": 88, "amount": 45000, "fee_amount": 2872,
  "status": "provided", "sender": {...}, "receiver": {...}
}

Eslatma: to'lov tizimi (InPay) har bir tranzaksiyadan 6% komissiya oladi. Mijozdan haqiqatda yechiladigan summa amount + fee_amount ga teng — servis balansiga esa to'liq amount qo'shiladi.

Xatolik 400 — allaqachon to'langan
{ "detail": "Application is already paid for this cycle" }
Xatolik 400 — summa oshib ketgan
{ "detail": "Cannot charge more than the agreed application amount" }
GET /transaction/?page=1&page_size=20 Bearer yoki API kalit

Tranzaksiyalar tarixi, paginatsiya bilan (eng yangisi birinchi).

Dasturchi

POST /developer/keys Faqat Bearer

Yangi API kalit yaratish. To'liq kalit faqat shu javobda bir marta ko'rsatiladi.

So'rov tanasi
{ "name": "Production server" }
Javob 201
{
  "id": 1, "name": "Production server",
  "key_prefix": "bnd_live_1i7_1epN",
  "key": "bnd_live_1i7_1epNioJJ...",
  "is_active": true
}
POST /developer/payouts Faqat Bearer

Balansingizdan bank kartangizga pul yechish so'rovi yuborish. Minimal summa 100 000 so'm, oyiga bitta so'rov. Admin so'rovni 3 ish kuni ichida ko'rib chiqib, qo'lda pul o'tkazadi.

So'rov tanasi
{
  "amount": 500000,
  "card_number": "8600123456789012"
}
Javob 201
{
  "id": 4, "amount": 500000,
  "card_number": "8600123456789012",
  "status": "pending"
}

Paginatsiya

Ro'yxat qaytaradigan barcha endpointlar page (standart: 1) va page_size (standart: 20, maksimal: 100) parametrlarini qabul qiladi va quyidagi formatda javob beradi:

{
  "items": [...],
  "total": 42,
  "page": 1,
  "page_size": 20,
  "total_pages": 3,
  "has_next": true,
  "has_previous": false
}

Xatoliklar

Xatoliklar standart FastAPI formatida qaytariladi:

{ "detail": "Xatolik haqida qisqacha ma'lumot" }

Eng ko'p uchraydigan status kodlar: 401 — autentifikatsiya xato, 403 — ruxsat yo'q, 404 — topilmadi, 400 — validatsiya/biznes qoidasi xatosi, 422 — so'rov formati noto'g'ri.
